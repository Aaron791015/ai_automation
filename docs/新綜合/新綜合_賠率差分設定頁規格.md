## 適用範圍與欄位結構

- 三彩種共用：香港六合彩（markSix）、英國天天彩（ukLucky7）、賓果六合彩（bingo6）。
- 適用賠率差分設定頁；依既有授權與權限存取各代理／會員設定，不因本文件放寬操作權限。
- 表頭包含「玩法」「赔率差分」「剩余差分」。每個玩法有主差分輸入及對應剩餘值；有副欄者，另須有副差分輸入與其對應剩餘值，不能用單一主欄代替。

- 「兩面」必須存在；五不中至十二不中每列只有一個輸入欄，不設本命年副欄。過關沿用既有裁定，不支援賠率差，不列入。

## 輸入判準

- 差分非正數限制沿用既有賠率差公式規格；正常保存測試包含具有整數與小數部分的非零值，例如-1.1。
- **正數輸入的拒絕方式（規格，Aaron 2026-10-02 裁定）**：輸入正數後，欄位下方顯示行內紅字「只允许输入最大值 0」，點「保存」不送出請求，重新載入後仍為原值。符合這三點即判 PASS；不要求彈窗或 toast。
- **輸入規則（規格，Aaron 2026-10-06 裁定：除「會被靜默存成別的值」的四種外，一律以新綜合現行行為為準）**：下表為現行判準。下方 10/02 兩條暫定規格（「超位小數、非數字、空白的處理」「特殊寫法的處理」）只剩表中標 ❌ 的四種仍適用，其餘項目以本表為準。現行行為依據：2026-10-02 與 10/05 實測（[T93 報告](bugs/_reports/需求驗證報告_賠率差分輸入行為對照環球六_T93_2026-10-02.md)、`Snotra-032`）。
  | 輸入 | 前端（畫面保存） | 後端（直接呼叫 API） |
  | --- | --- | --- |
  | 最多 4 位小數（如 `-0.1234`） | 照存 | 照存 |
  | 超過 4 位小數（如 `-0.12346`） | 四捨五入到 4 位後保存（→ −0.1235），不需提示 | 拒絕，回「最多 4 位小数，总位数不超过 12 位」 |
  | `-0`、`0.0000`、`-01.1` | 存成 0、0、−1.1 | — |
  | `-.5`、`-1.` | 存成 −0.5、−1 | 存成 −0.5、−1 |
  | 正數 | 行內紅字「只允许输入最大值 0」、不送出（10/02 裁定，見上條） | — |
  | 貼上 | 與手動輸入同一套規則，前後空格自動去掉 | — |
  | 負值下限 | 不設下限，只限總位數不超過 12 位 | 同左 |
  | ❌ 非數字（`abc`、`--1`） | **應阻擋並提示、不保存**（現況存成 0，`Snotra-032`） | 拒絕，回「请求格式错误」 |
  | ❌ 清空 | **應阻擋並提示、不保存**（現況存成 0，`Snotra-032`） | `null`、空字串拒絕，回「请求格式错误」 |
  | ❌ 含逗號（`-1,000`） | **應阻擋並提示、不保存**（現況拿掉逗號存成 −1000，`Snotra-032`） | 字串拒絕，回「请求格式错误」 |
  | ❌ 請求少帶該欄位 | — | **應拒絕、資料不變**（現況接受並存成 0，`Snotra-032`） |

  判定方式：「照存／存成」——可保存，重載與 API 讀回皆為表中的值；「應阻擋」——該值無法保存成功、重載後仍為原值，且看得到提示（提示文字仍依下方「提示內容」條，用字確認前只判有無）。B91 的超位小數條件自本條起有判準，不再列 BLOCKED。（2026-10-06 補：B91 自動化已依本條實作——照存類 11 條＋貼上 1 條、應阻擋類 4 條＋貼上 1 條，正數與超扣判定不變；見《賠率差驗收操作》B91 列。）
- **超位小數、非數字、空白的處理（暫定規格，Aaron 2026-10-02 16:00；16:10 Aaron 補充：來源是「環球六」的規格，新綜合暫時比照；之後若與 RD 確認結果不同再更新）**：①**小數最多四位**；超過四位時，前端與後端都要阻擋、不接受該輸入，並顯示提示。②**文字與其他非數字內容**：前端與後端都要阻擋、不接受該輸入，並顯示提示（16:10 補）。③**空白**：前端與後端都要阻擋、不接受，並顯示提示。判定方式：前端——該值無法保存成功（打不進去，或保存時不送出／被拒），重載後仍為原值，①②③都須看得到提示；後端——不經畫面直接送該值到 API 時回拒絕、資料不變。本條取代下方兩條「待確認」。**仍未定**：貼上的處理、負值下限。
- **提示內容（Aaron 2026-10-02 16:10 提供，環球六的規格）**：「请输入正确的赔率，最多三位小数」。⚠️ **待 Aaron 確認**：這句寫「最多三位小数」，與上一條「小數最多四位」不一致（環球六的欄位可能是三位；新綜合差分是四位）。確認前，提示只判「有沒有出現」並記錄實際文字，不以文字內容判 PASS／FAIL。
- **特殊寫法的處理（暫定規格，Aaron 2026-10-02 16:05 逐項指定；來源同為環球六的規格）**：
  | 輸入 | 處理 |
  | --- | --- |
  | `-0` | 自動存成 `0` |
  | `0.0000` | 自動存成 `0` |
  | `-01.1`（前導零） | 自動存成 `-1.1` |
  | `-.5`（省略整數） | 拒絕並提示 |
  | `-1.`（小數點後沒有數字） | 拒絕並提示 |
  | `--1`（兩個負號） | 拒絕並提示 |
