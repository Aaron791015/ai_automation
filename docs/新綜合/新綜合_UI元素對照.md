### 「飛單選項設置」頁欄位 —— ⚠️ 分兩種結構家族，欄位名稱不同

「飛單選項設置」共 25 個玩法分類，分兩種結構家族，**各自的自留上限欄位名稱不一樣**，
不可互相取代或當成同一件事的兩種寫法：

| 結構家族 | 涵蓋玩法（15＋10＝25） | 本結構專用的欄位 UI 名稱 |
| --- | --- | --- |
| **標準選項清單型**（15 個） | 特码、正码、正特码、两面、生肖中、生肖不中、半波、特肖、尾数中、尾数不中、色波、七码、五行、一肖量、尾数量 | 占成、**每選項自留上限**、自動飛單 |
| **組合型**（10 個） | 连码、过关、六肖、连肖、连尾、不中、多选中一、特平中、合肖、比大小 | **組合占成金額**、**共用自留上限** |

> ⛔ **常見錯誤**：把「每選項自留上限」寫成「共用自留上限」，或反過來——
> 兩者是不同結構家族**各自的正式 UI 文字**，寫案例時要先確認在測哪個結構家族的玩法，
> 再套用對應欄位名稱，不可挑一個當通用說法。

後端是同一個 API 資源，25 個分類只差 `gameId`／`playTypeId`，UI 差異純屬前端客製化渲染。

### 4.1 表格 DOM 結構（2026-09-16 實測，開發賠率差 pytest 框架時發現）

- 佔成報表的 `<thead>` 是**兩層**：第一層為分組表頭（「会员」colspan=4／「一级代理」colspan=2／「公司」colspan=8），另有第一欄「帳號」與第二欄「昵称」各 rowspan=2；第二層才是實際對應 tbody 的 14 個葉欄。**直接 `thead th` 會讀到 19 個表頭，但 tbody 每列只有 16 個 `td`** —— 依表頭出現順序去對應欄位會整排錯位，必須依 rowspan/colspan 展開後才能正確配對。
- **第一欄的欄名會隨下鑽層級變動**（公司層顯示「一级代理」，下鑽一層後變「二级代理」……），不存在固定的「账号」欄名；不可拿欄名字串當鍵去找該欄，否則會讀回空 dict，出現「UI 與 API 一致」的假通過（兩邊都是空值）。
- 葉欄名有重複（「盈亏」出現 3 次），須用「分組／葉欄」的合成名稱才能唯一指到「赔率差金额」。
- 正確讀法已實作於 [`tools/xzh_qa/pages/odds_gap_report_page.py`](../../tools/xzh_qa/pages/odds_gap_report_page.py) 的 `_READ_TABLE_JS`，新增讀表格的案例直接沿用該函式，不要重寫一份 thead 解析。

### 4.2 篩選控制項的實際型別（2026-09-16 實測）

- 「结算状态」是 **radio**（`已结算`／`未结算`，同一個 `name`），不是下拉選單。2026-09-29 實測：外觀是 el-segmented，radio input 為隱藏元素，直接 `check()` 會逾時；須點包含該 input 的可見 `.el-segmented__item`，再核對已選中（「已结算」是預設值，所以只查已結算時不會發現）。
- 日期起訖是 placeholder 為「开始日期」「结束日期」的 input（`role=combobox`）。
- 彩種篩選是「游戏 14/14」按鈕展開後的一組 checkbox，**預設 14 個全選**；送出查詢的 API 參數 `gameIds` 是**重複出現的同名參數**（`gameIds=a&gameIds=b`），不是逗號分隔字串。讀報表時若沒注意到預設全選，容易誤以為查詢只涵蓋賠率差適用的三個彩種。
- 2026-09-16 補驗：checkbox 的 `input.el-checkbox__original` 是隱藏元素；先點「清除」，再點包含指定 checkbox 的可見 `label.el-checkbox`，最後用 `is_checked()` 核對。直接 `.check()` 隱藏 input 會逾時，屬定位問題。
- 另有快捷按鈕「今天／昨天／本周／上周／本月／上月」，以及「查询」「返回」。

### 4.3 導覽選單定位陷阱（2026-09-16 實測）

### 4.4 注單查詢完整性與資料來源（2026-09-16）

## 6. 注单数据 → 注单明细（2026-10-05 MCP 實測：公司 aaron01）

入口：公司後台頂部選單「注单数据」→ 上方彩種卡片點要看的彩種（預設停在第一個彩種）→ 左側「注单明细」（另一個是「注单概览」）。網址 `/bet/detail`，資料來自 `GET /api/Bets/Details`。

- 欄位：注单编号／会员／投注时间／玩法／号码／投注金额／**赔率**／**公司赔率**／中奖／下级实付／下级退水／状态。「赔率」＝回應的 `odds`（會員成交價），「公司赔率」＝`companyOdds`。這是後台**唯一同時列出兩個賠率**的畫面；占成報表下鑽到的注單明細只有「赔率」。
- 篩選：日期（日期選擇器）、期号（下拉）、账号（文字框，逐字輸入即時查詢，不必按查詢鈕）。
- ⚠️ **期号下拉只列最近 10 期**（賓果約 50 分鐘內）。要在畫面上看某一期，得在它掉出清單前操作；較舊的期只能用 API 帶 `issueNumber` 讀（讀取驗證，可用公司登入後 `localStorage.accessToken`）。
- ⚠️ 期号下拉的 `combobox` 被已選值的 `span` 蓋住，直接點 `getByRole("combobox", name="期号")` 會逾時；要點該表單項裡的 `.el-select__wrapper`。
- 有公司手動偏移時「公司赔率」不含偏移，見 `Snotra-033`。
