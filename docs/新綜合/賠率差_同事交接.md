## 3. 現行規格速查

### 3.1 設定、授權與收益歸屬

- 每彩種 **101 個玩法設定列、101 個主欄＋15 個副欄＝116 個輸入欄**。十層三彩種合計 **3,480 個有效輸入欄**。
- 全表還原常見的 **6,060 格**是 101 列 × 主副兩欄 × 十層 × 三彩種，含不適用或空的副欄；與 3,480 個可輸入欄的分母不同。
- 差分是 **0 或負數**，以小數四位為設定精度。上級可設定所管轄的下級，不限直屬；收益歸屬仍是被設定者的**直屬上級**。例如設定三級代理的差分，受益者是二級代理。
- 生效取決於平台開關、受益代理授權等條件；畫面保留數值不代表當下已生效。撤銷後原值保留，恢復授權才重新生效。
- 關閉代理授權時，直屬下級代理若仍開啟「赚取赔率差」，須阻擋並維持原值；需由最下層向上關閉。會員沒有此授權開關，不把會員差分的生效旗標當成會員授權。
- 剩餘差分不納入子孫設定；現行規格**保存不檢查超扣**，不能因超扣仍可存就另開缺陷。
- 過關不支援賠率差，不列入設定及計算驗收。

### 3.2 設定及成交價公式

```text
差分總合上限＝（玩法基準賠率－玩法最低賠率）×當次平台上限比例
剩餘可扣差分＝差分總合上限＋本層差分＋祖先鏈差分合計

一般單一賠率玩家成交價＝max（玩法最低賠率，公司解析賠率＋鏈上生效差分合計）
本級有效實得差 diff_N＝本級與直屬下級在下限截斷後的有效賠率差
```

公司解析賠率包含基準、盤口、跳水及手動調整；剩餘公式使用的是基準賠率，兩者不能混用。下限造成差分無法全額生效時，依**最深層優先縮減**核算有效差，不能直接把設定差分的絕對值當成收益差。

示例：公司解析 49、最低 1，鏈上生效差分 −2 與 −3，成交價為 `max(1,49−2−3)=44`。數字只是示例，正式重驗需讀當下設定。

### 3.3 特殊玩法

| 類型 | 判準 |
| --- | --- |
| 生肖／尾數／五行 | 選中適用期別的副標籤時用副差分、副下限；其他選項用主層。副差分未設視為 0，不誤扣主差分 |
| 連肖／連尾 | **各成員先套差分及有效下限，再比最低成交價**；主副同價取主層，不因選號順序改變。有副標籤成員不代表必定走副鏈 |
| 連類有效下限 | 含例外成員時，候選有效下限＝`min(該層設定下限,候選解析價)`；候選成交價＝`max(有效下限,候選解析價＋該層生效差分合計)`，不能反向抬高較低的解析價 |
| 二中特／三中二 | 投注時保留主、副兩套；依實際中獎分支擇一結算，不重複算收益 |
| 七碼 | 8 個代表設定：單 k＝大 k＝雙(7−k)＝小(7−k)，每組同步影響四葉 |
| 兩面 | 位置大小／單雙／尾大小／合單雙、總和大小／單雙／尾大小，共用一組差分 |
| 五不中～十二不中 | 八個玩法各自只有一個差分輸入欄，不設本命年副欄；與「生肖不中」不同 |

本檔歷史案例中的「馬」是當次副標籤，**不得永久固定沿用**。每次依賴生肖號碼對照時，先確認彩種、日期、時區、期別與核准生效表，留下來源及查證時間；沒有可信版本就暫停依賴該表的判定。

### 3.4 結算與報表（10/06 新判準）

```text
上繳額 remit(N)
＝投注額－凍結的總控鏈前占成額－凍結的總控鏈後占成額
        －本級至九級凍結占成額合計

中獎時該注該層收益＝round_half_up(remit(N) × diff_N, 4)
報表收益＝逐注取四位後的收益加總

玩家派彩＝round_half_up(投注額 × 中獎分支的凍結賠率, 2)
```

- 四捨五入是剛好一半進位，不是銀行家捨入。例：4.025 → 4.03。收益不得先合計未取位值才一次取四位。
- 輸局、和局退本的賠率差收益為 0；和局玩家退本金。`diff_N=0` 或 `remit(N)=0` 時收益亦為 0。
- 舊注使用**下注時凍結**的賠率、差分與占成，不以目前設定重新解釋。三中二中三等副分支不能只拿注單主賠率欄算派彩。
- 收益進報表，不直接加進代理餘額或帳變；公司為報表查看根層時賠率差欄為 0。未結算模式不提供此欄。
- 同會員、日期、彩種、玩法及選號可能聚合多批注單；核對前須盤點所有重疊注單。
- 示意：投注 1,000、本級以下凍結占成合計 600、無總控扣額、有效差 2，中獎收益為 `(1000−600)×2=800`；不是直接入餘額 800。

### 3.5 輸入限制（以 2026-10-06 裁定為準）

| 輸入 | 應有結果 |
| --- | --- |
| `-0.1234` | 保存原值 |
| `-0.12346` | 前端四捨五入成 −0.1235 後可保存、不需提示；後端直接收到超過四位則拒絕 |
| `-0`／`0.0000`／`-01.1` | 分別存成 0／0／−1.1 |
| `-.5`／`-1.` | 前後端接受，存成 −0.5／−1；不再當缺陷 |

| 貼上 | 同手動輸入規則，前後空格可自動去掉 |
| 負值 | 不另設下限，但總位數不超過 12 位 |
