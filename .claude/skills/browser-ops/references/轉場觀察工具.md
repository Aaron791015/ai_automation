### 5.1 取樣器的裝法（一次裝好、之後只讀結果）

```
browser_evaluate  function=() => {
  window.__frames = []; window.__t0 = null;
  const read = () => ({ /* 你要追的 DOM 狀態 */ });
  let last = null;
  const tick = () => { if (window.__t0===null) { requestAnimationFrame(tick); return; }
    const s = read(), k = JSON.stringify(s);
    if (k !== last) { last = k; window.__frames.push({t_ms: Math.round(performance.now()-window.__t0), ...s}); }
    if (performance.now()-window.__t0 < 8000) requestAnimationFrame(tick); };
  window.__armed && document.removeEventListener('click', window.__armed, true);
  window.__armed = () => { if (window.__t0===null) { window.__t0 = performance.now();
                             window.__frames.push({t_ms:0, ...read(), mark:'click'}); } };
  document.addEventListener('click', window.__armed, true);   // capture 階段＝時間原點
  requestAnimationFrame(tick); }
```
→ 接著 `browser_click` 觸發 → 再 `browser_evaluate function=() => JSON.stringify(window.__frames)`。

⚠️ **重複裝要先 `removeEventListener` 舊的那個** —— 舊 listener 還在的話會先搶到 `__t0`，
你會看到第一筆 frame 的欄位是上一版 `read()` 的格式（實際踩過，一度以為取樣壞了）。

### 5.2 慢 API 情境要用 route 模擬（別空等）

RD 常說「API 超過 N 秒才會出 loading」。QAT 的 API 往往快到永遠觸發不了，
**不能因此寫「無法驗證」** —— 用 `browser_run_code_unsafe` 攔截並延遲即可：

```js
async (page) => {
  await page.unroute('**/api/…/TheEndpoint**');          // 重裝前先 unroute
  await page.route('**/api/…/TheEndpoint**', async route => {
    await page.waitForTimeout(1500);                      // ⚠️ 不能用 setTimeout
    await route.continue();
  });
}
```

- ⛔ **route handler 裡沒有 `setTimeout`**（跑在 Playwright server 端，不是瀏覽器）——
  會直接 `ReferenceError: setTimeout is not defined`。用 `page.waitForTimeout`。
- 要截到「載入中」的畫面，**點擊＋等待＋標注＋截圖全部塞進同一個 `browser_run_code_unsafe`**；
  分成多次 MCP 呼叫的話，往返時間會超過遮罩存在的區間，拍到的是載入完成的畫面（實際踩過一次）。
- 報告中須註明「此項以 route 延遲模擬」，不可寫成自然情況下的實測值。

### 5.3 `browser_evaluate` 傳不了自訂參數

`browser_evaluate` 的 `element`/`target` 是**給元素用的**，函式簽名只有 `()` 或 `(element)` ——
**沒有辦法傳自己的 payload 進去**（傳了會靜默變成 `undefined`，例如標注一個都沒畫出來卻回報成功）。

兩種解法：① 把參數**寫死在函式字面**裡；
② 先 `window.__helper = (payload) => {…}` 裝一次，之後每次呼叫 `() => window.__helper({...})`。
`tools/qa_common/shot.py` 的 `ANNOTATE_JS` 需要 `{marks, note}`，屬於必須走②的典型。
