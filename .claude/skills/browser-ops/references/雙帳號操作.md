# 同時用兩個帳號操作 UI

> 由 `browser-ops` §0 移出（2026-08-23）。**內容一字未改。**
>
> **什麼時候讀這份**：這次要**同時以兩個身份**看同一個站台 ——
> 例如比對主帳號 vs 子帳號看得到什麼、上級 vs 下級的報表數字、股東 vs 代理的權限。
> 單一身份操作用不到這裡。
>
> ⛔ **先知道一件事就好**：**不要用「開分頁」登入不同帳號** ——
> token 存在 `localStorage`、同源共享，後登入的會覆蓋先登入的，
> 但先登入分頁**已渲染的畫面不會變**，形成「畫面是 A、資料是 B」的殘影且無任何警示。
> 怎麼做才對，見下。

---

### ⛔ 不要用「開分頁」登入不同帳號做比對

看似能省下反覆登入的時間，實際上**會讓資料張冠李戴**。

CRUX／七星／wbot 的 token 都存在 **`localStorage`**（如 `localStorage.jwtToken`），
而 **localStorage 是同源共享**的 —— 後登入的分頁會**覆蓋**先登入分頁的 token，
但先登入分頁**已渲染的畫面不會變**，形成「**畫面是 A、資料是 B**」的殘影，且無任何警示。

> 實測（2026-08-12，CRUX QAT b1.d2）：分頁 0 登入股東 `perfsh01`、分頁 1 登入代理 `perfag01` 後，
> 回到分頁 0 —— 畫面頂端仍寫「股东：perfsh01」，但該分頁發出的
> `GetSummaryReport` 回 `selfAccount: perfag01`，列出的是 perfag01 的 47 個會員。
> 兩分頁的 `jwtToken` 尾碼完全相同。若照此記錄數據，會把 B 的數字寫成 A 的。

### ✅ 要「兩個帳號同時操作 UI」→ 用第二個 MCP 瀏覽器

`.mcp.json` 已配置**兩個獨立的 Playwright MCP server**，兩者各自 `--isolated`，
**各有自己的瀏覽器實例與 localStorage**，token 不會互相覆蓋：

| server | 工具前綴 | 建議用途 |
| --- | --- | --- |
| `playwright` | `mcp__playwright__browser_*` | 主要身份（CRUX 總監2 用 `netsub2`） |
| `playwright2` | `mcp__playwright2__browser_*` | 對照身份（中間商／另一個子帳號；CRUX 總監2 用 `netsub4`） |

- 兩組工具**用法完全相同**，只差前綴；各自獨立 `browser_navigate`／`browser_close`。
- ⚠️ **不用就不會啟動瀏覽器**（MCP server 於首次呼叫 `browser_*` 時才開），閒置無成本。
- ⚠️ 兩邊**必須用不同帳號** —— 站台是同帳號他處登入即踢掉前者（見上表），
  同帳號開兩個瀏覽器只會互踢。
- ⚠️ **用畢兩邊都要 `browser_close`**。
- ⚠️ 新增 server 後**需重啟 session** 才會載入該組工具。

### 只做「讀取比對」時：多 token 並存更快

不需要兩個瀏覽器 —— **在同一個瀏覽器裡收集多份 token，用 fetch 指定身份**即可：

```js
// ① 登入 A，把 token 收起來（存進 window，不動 localStorage）
window.__tok = {A: localStorage.getItem('jwtToken')};
// ② 登入 B（localStorage 被覆蓋沒關係），再收一次
window.__tok.B = localStorage.getItem('jwtToken');
// ③ 之後任意切換身份做「讀取驗證」，完全不必重登
const as = (who,url) => fetch(url, {headers:{Authorization:'Bearer '+window.__tok[who]}}).then(r=>r.json());
const [a,b] = await Promise.all([as('A','/api/...'), as('B','/api/...')]);
```

- ⚠️ 頁面**重新導航會清掉 `window.__tok`** → 收集完 token 後就別再 `browser_navigate`，或改存到
  一個不會被清的地方（例如先把兩份 token 印出來，之後每次 evaluate 直接內嵌字串）。
- ⚠️ 僅適用**讀取驗證**；**被測行為一律走 UI**（CLAUDE.md §5），UI 操作仍須逐一登入切換。
- ⚠️ 同帳號他處登入會互踢（見上一列），但**不同帳號**的 token 可並存不衝突。
