## 1. 前置檢查（逐項打勾）

```powershell
python -m scripts.preflight_check --all      # 站台／總監登入／期數狀態／會員清單／下注資料／DB
```

| # | 檢查 | 不通過時 |
| --- | --- | --- |
| 1 | **確認是哪一個彩種的站台** —— 三彩種在 QAT 是**各自獨立站台**（`l5_*` director2／`ss_*2` director4／`p5_*` director2） | 打錯站台等於在別人的環境下注 |
| 2 | 期數可下注（**低頻站台常處於封盤**） | 見下方 §2 推進一期 |
| 3 | 會員清單足量 | `python -m scripts.build_perf_accounts --lottery <彩種> --suffix <新suffix> --target-members 300 --apply`<br>（三站台各已有 300 個 `qp2` 會員；要再建**換一個 suffix**） |
| 4 | 下注資料已建（**已 gitignore，clone 後要重建**） | `python -m scripts.build_bet_data --lottery <彩種>` |
| 5 | **users ≤ 清單帳號數 − 1** | 清單**最後 1 個帳號保留給期號追蹤器**；超用會互踢 |
| 6 | DB 對照（可選） | lucky5 的 QAT DB **不在 192.168.51.245**（待補），缺它只略過 DB 對照，不影響下注 |

## 2. ⛔ 低頻站台：推進一期要五步，缺一不可

**期到自動封盤 ≠ 關盤。**「快速初始化」**不會推進期號**。

```powershell
python -m scripts.manage_period --lottery p5 status
python -m scripts.manage_period --lottery p5 advance   # 關盤 → 結算 → 前台顯示 → 新增期 → 開盤
```

## 3. 四個會讓數據靜默失真的陷阱

| # | 陷阱 |
| --- | --- |
| 1 | **玩法不同**：lucky5 高頻 5 分鐘一期、**無包牌**，多一定位（型別 19~23）／五位二定（15~18）。<br>**快選 `MultipleBet` 三站台都只吃 4 位號碼**，5 位型別只能走文字 `BatchBet` |
| 2 | **低頻站台常處於封盤**（見 §2） |
| 3 | **同帳號他處登入互踢** —— 見上表第 5 項 |
| 4 | **金額規則**：低頻須**整數且 ≥1**、高頻 0.1 起；<br>**同一組下注資料連送會被「重复提交」擋 → 每輪換組** |

---

## 4. 執行範例

```powershell
# 高頻：跑滿 1 個完整期（實際會經過 3 個期號 ≈ 15 分鐘）
python -m runner.locust_main --lottery lucky5 -u 50 -r 10 --stop-mode periods --max-periods 1

# 低頻：3 分鐘，1 分鐘後由總監關盤結算並重開新期
python -m runner.locust_main --lottery p5 -u 50 -r 10 -t 3m --director --delay 1
```
